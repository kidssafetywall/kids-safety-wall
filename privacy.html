隱私權政策

最後更新：2026年6月15日

本站為純靜態網站，不設有後端伺服器，不會主動儲存您的個人資料。

一、我們收集哪些資料

本站（兒少防火牆）本身不收集、不儲存任何識別個人身份的資料。您在本站上的搜尋關鍵字與瀏覽行為，不會被本站記錄或傳送至任何本站控制的伺服器。

以下資料可能由第三方服務自動收集：

  • GitHub Pages（網站託管）：本站架設於 GitHub Pages，GitHub 可能依其隱私政策收集基本的伺服器存取日誌（如 IP 位址、存取時間）。
  • Portaly（捐款服務）：若您點擊「支持我們」連結前往 Portaly 捐款頁面，您的付款資料及電子郵件由 Portaly 處理，適用 Portaly 的隱私政策。

二、Cookie

本站不主動設置任何 Cookie。GitHub Pages 或瀏覽器本身可能有基本的技術性 Cookie，但本站不使用 Cookie 追蹤用戶行為，也不使用廣告 Cookie。

三、本站展示的資料

本站展示的教育機構相關資料（裁罰紀錄、司法判決、新聞等）均來自以下公開資料來源：

  • 教育部及各縣市教育局處公告之裁罰紀錄
  • 司法院公開裁判書資料庫
  • 公開新聞報導

上述資料為政府或媒體依法公開之資訊，本站以彙整方式呈現，不涉及非公開個人資料的收集或揭露。

四、兒童隱私

本站服務對象為家長及成人使用者。本站不針對兒童收集任何資料，也不鼓勵兒童提交個人資訊。

五、聯絡我們

若您對本隱私權政策有任何疑問，或認為本站展示的資料有誤，請透過以下方式聯絡我們：
